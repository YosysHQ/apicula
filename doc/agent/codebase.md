# The codebase, building and devices

An orientation for agents. The rules are in [`AGENTS.md`](../../AGENTS.md).

## Flow

Verilog → Yosys (synthesis) → nextpnr (place and route) → `gowin_pack`
(bitstream) → openFPGALoader (program the FPGA).

## Building

Install for development:

    pip install -e .

Build the chip databases (needs the IDE version in `GWVERSION`):

    export GOWINHOME=/path/to/gowin
    PATH=$PWD/.venv/bin:$PATH make -j4

Build the examples, or one of them:

    cd examples
    make -j$(nproc) all
    make blinky-tangnano9k.fs

## Console entry points

- `gowin_pack`: nextpnr JSON to bitstream (`.fs`).
- `gowin_unpack`: bitstream back to Verilog, for verification.
- `gowin_pll`: PLL configuration calculator.

## Main components (`apycula/`)

- `gowin_pack.py`: the bitstream packer. Reads nextpnr JSON, sets fuses for
  routing, LUTs, IOBs and the rest, and writes the bitstream.
- `gowin_unpack.py`: the reverse, for verification.
- `chipdb.py`: device database structures (Device, Tile, BEL, PIP) and helpers.
- `chipdb_builder.py`: builds the chip database from the vendor files, including
  SDRAM pin discovery.
- `bslib.py`: bitstream I/O and CRC.
- `wirenames.py`: wire ID to name (0–31 LUT inputs, 32–39 LUT outputs, …).
- `attrids.py`: attribute IDs and values.
- `fse_parser.py`, `dat_parser.py`, `tm_parser.py`: parsers for the vendor's
  `.fse` (fuses), `.dat` and `.tm` (timing) files.
- `fse_formats.py`: generated by `tools/gowin_extract.py`; never edit by hand.

## Chip databases

`apycula/*.msgpack.xz` are the compressed device databases built by
`chipdb_builder.py`: tile grid, wires, fuse tables, pins and timing.

## Wire names

`{direction}{length}{number}{segment}`: direction N/S/E/W, length 1, 2 or 8 hops.
`W270` is west two-hop wire 7, segment 0.

## Bitstream structure

Frames are one row of bits across the tile grid, padded to bytes, with CRC-16
checksums. A logic tile is roughly 60×24 bits: LUTs in the bottom 4 rows, routing
multiplexers in the top 20.

## Devices

- GW1N: GW1N-1, GW1N-4, GW1N-9, GW1N-9C, GW1NZ-1
- GW1NS: GW1NS-2, GW1NS-4
- GW2A: GW2A-18, GW2A-18C
- GW5A: GW5A-25A
- GW5AST: GW5AST-138C

For "C" devices, pass the family (`GW1N-9C`) to nextpnr's `--vopt family` and to
`gowin_pack -d`, not the full device ID.
